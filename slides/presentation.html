3目的
FPGA上にRISC-Vプロセッサを実装し，パイプライン処理を導入することで
実行時間・消費電力・消費電力量を改善することを目的とする

背景

  • クロック周波数の向上だけでは性能改善に限界がある
  • パイプライン化はCPU高速化の基本的・実用的な手法
  • 段数増加は 周波数↑ と CPI↑ のトレードオフを伴う

評価方針

  • 逐次実行CPUを基準として定量比較
  • 2段PL / 5段PLの効果を実測データで評価
  • 評価指標：実行時間・CPI・LUT・消費電力・消費電力量
  • プラットフォーム：Xilinx Artix-7 FPGA

4高速化設計の方針
Step 1　アルゴリズム選択

選択ソートとクイックソートを実装し，実行命令数の少ない方をパイプライン化の対象に採用する．

→ クイックソート採用（約29倍少ない）
Step 2　動作周波数の向上

パイプラインレジスタで段間を分割しクリティカルパスを短縮することで，より高い周波数での動作を実現する．

周波数 ∝ 1 / クリティカルパス長
Step 3　パイプライン化

命令実行を複数ステージに分割し，複数命令を並列処理することでスループットを向上させる．

段数↑ → 周波数↑（好）かつ CPI↑（悪）
ハザードによるストール・フラッシュが原因

3経路フォワーディング（riscv.v 208〜282行）

① WB→ID 3命令差 — WB_RD_VAL（組み合わせ）を直接転送
② EX/MEM→EX 2命令差 — LOAD・MUL は結果未確定のため除外

ストール・フラッシュ（riscv.v 419〜442行）

LOAD-USE / MUL-USE → 1サイクルストール
LOADのメモリ結果・MULの乗算結果はEXステージで未確定 → フォワーディング不可
分岐成立 → 2サイクルフラッシュ
EXで分岐確定 → IF+IDの2段分をNOP化

12考察

実行時間の改善

2段PLは周波数向上（+43%）がCPI増加（+15%）を上回り，実行時間を約20%短縮（1.24×）できた．

5段PLはさらに高周波（+67%）だが，分岐の2サイクルフラッシュ・LOAD-USE・MUL-USEストールによりCPIが大幅増加（+39%）し，改善幅は約20%（1.20×）にとどまった．

トレードオフの整理

パイプライン段数増加は ① 周波数向上 と ② CPI増加 のトレードオフを伴う． 段数を増やせば必ず速くなるわけではない．

消費電力量の改善

5段PLはメモリサイズを 32kW → 2kW（1/16）に削減したことで，消費電力が 0.384 → 0.225 W（−41%）と大幅低下．

消費電力量（P×T）は逐次比で約51%削減（0.912 → 0.447 mJ）．

2段PLは電力増加と時間短縮が相殺し，ほぼ変わらず（−1.3%）．
注意点
5段PLのエネルギ改善は，パイプライン化自体の効果よりメモリ削減の効果が支配的であった点に注意が必要

13まとめ
  • クイックソートは選択ソートに比べ実行命令数が約29倍少なく，パイプライン化の対象アルゴリズムとして採用
  • 2段パイプライン：実行時間を約20%短縮（2.376 ms → 1.914 ms，1.24×高速化）
  • 5段パイプライン：消費電力量を約51%削減（0.912 mJ → 0.447 mJ）
  • 5段パイプライン：LUT使用率を 29.90% → 3.65% に大幅削減（メモリサイズ縮小が主因）
  • パイプライン化は 周波数向上（高速化） と CPI増加（効率低下） のトレードオフを伴う
  • 目的・用途に応じてアルゴリズムとアーキテクチャを適切に選択することが重要
